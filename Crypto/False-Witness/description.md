# False Witness
Difficulty: **very easy**

## Challenge Description

### False Witness

Caldrin Vowmark knows that not every seal deserves belief.  
Some marks still carry the weight of a living vow; others only imitate one well enough to pass a glance.  
She can question the realm's witnesses as many times as she likes, but certainty, it turns out, is much harder to earn than a convincing lie.
